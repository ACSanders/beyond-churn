# Data

Beyond Churn uses the public **Orange Belgium churn uplift dataset** for studying churn prediction, heterogeneous treatment effects, uplift modeling, and retention targeting.

## Source

The dataset is publicly available through OpenML:

- Dataset name: `churn-uplift-orange`
- OpenML dataset ID: `45580`

The raw dataset is not committed to this repository.
